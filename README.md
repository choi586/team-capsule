# 조이! — QR 랜덤 조 편성

QR로 참가자의 이름을 모으고, 관리자가 정한 조 수에 맞춰 최대 25명을 균등하게 랜덤 배정하는 웹앱입니다.

## 사용 방법

1. 사이트의 기본 주소를 관리자 기기에서 엽니다.
2. 화면의 QR을 참가자에게 보여 줍니다.
3. 참가자는 이름을 입력하고, 관리자는 도착한 명단을 확인합니다.
4. 관리자가 조 수를 정하고 `명단 잠그고 시작`을 누릅니다.
5. 이름이 한 명씩 조에 들어가는 연출 뒤 전체 결과를 확인합니다.

관리자는 빠진 이름을 직접 추가하거나 잘못 들어온 이름을 지울 수 있습니다. 완료 후 결과 복사, CSV 저장, 같은 명단 다시 섞기도 지원합니다.

## 동작 방식과 개인정보

- 별도 회원가입이나 데이터베이스 설정 없이 사용할 수 있습니다.
- 참가 링크의 임시 열쇠로 메시지를 AES-GCM 암호화하고, 참가자 화면은 관리자 ECDSA 서명이 확인된 결과만 받아들입니다.
- QR의 열쇠는 URL 조각(`#`)에만 들어가므로 GitHub Pages 서버에는 전송되지 않습니다.
- 실시간 전달에는 공개 `ntfy.sh` 릴레이를 사용합니다. 릴레이에는 암호문만 전달되지만, 무료 공개 서비스이므로 중요한 개인정보를 입력하는 용도로는 사용하지 마세요.
- QR을 가진 참가자끼리는 같은 방의 정보를 공유합니다. 수업·워크숍처럼 이름과 최종 조가 서로 공개되는 상황을 전제로 합니다.
- 관리자의 브라우저가 최종 명단과 결과를 보관합니다. 진행 중에는 관리자 탭을 닫지 않는 것이 가장 안전하며, 실수로 새로고침해도 같은 브라우저에서는 최대 12시간 동안 복구됩니다.
- `새 방`을 누르면 관리자 기기의 현재 명단과 결과가 지워지고 기존 QR이 종료됩니다.

학교나 행사장의 네트워크가 WebSocket 또는 `ntfy.sh`를 차단하면 참가자 이름이 실시간으로 도착하지 않을 수 있습니다. 이 경우 관리자 화면의 이름 직접 추가 기능으로 추첨을 계속할 수 있습니다.

## 로컬 실행

Node.js 22.13 이상과 pnpm 11이 필요합니다.

```bash
pnpm install
pnpm dev
```

검사와 정적 빌드:

```bash
pnpm check
pnpm test:relay
```

`test:relay`는 실제 `ntfy.sh` 네트워크 연결을 사용하므로 인터넷 연결이 필요합니다.

## GitHub Pages

`main` 브랜치에 푸시하면 GitHub Actions가 테스트와 빌드를 실행하고 `dist/` 결과를 GitHub Pages에 게시합니다. 저장소의 Pages 소스는 **GitHub Actions**로 설정해야 합니다.
